# Enemy Killer

Enemy Killer is a simple Mindustry mod designed to help players learn and complete the campaign without constantly fighting enemy units.

The mod automatically removes enemy units, allowing players to focus on learning game mechanics, building factories, managing resources, and understanding production systems without the pressure of enemy attacks.

Perfect for beginners who want a more relaxed learning experience or players who want to explore campaign sectors without dealing with enemies.

## Features

- Automatically eliminates enemy units
- Helps new players learn Mindustry mechanics
- Makes campaign progression more relaxed
- Simple and lightweight

## Installation

1. Download the mod ZIP file.
2. Open Mindustry.
3. Go to **Settings → Mods → Import Mod**.
4. Select the downloaded ZIP file.

Enjoy learning Mindustry at your own pace! 🚀
